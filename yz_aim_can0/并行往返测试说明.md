# 两路单轴并行往返测试

在板子终端运行一条命令即可同时启动CAN0和USB-CAN两路。脚本默认CAN0节点2、USB节点1，使用原单轴程序，不使用双轴程序；不会改电机节点号、零点、波特率设置或原C++程序。

```bash
python3 -B /root/yz_aim_can0/parallel_cycle_test.py --can0-node 2 --usb-node 1
```

每一路按以下顺序重复约30分钟：`jog 300 3000`，确认已停止并保持1000ms，再`jog -300 3000`，确认停止后开始下一组。反转后不另外等待1秒。正负方向按电机自身方向，不使用extend/retract镜像映射。两路并行、各自按反馈推进，不保证长期相位对齐或位置同步。

交换接线后只更改寻址参数：

```bash
python3 -B /root/yz_aim_can0/parallel_cycle_test.py --can0-node 1 --usb-node 2
```

也可以从`/root/yz_aim/parallel_cycle_test.py`启动，功能相同。两个入口只需运行一个。

只查看计划（不开CAN，不使能，不创建测试日志）：

```bash
python3 -B /root/yz_aim_can0/parallel_cycle_test.py --can0-node 2 --usb-node 1 --dry-run
```

可调整速度、时间和USB设备参数，例如先做1分钟测试：

```bash
python3 -B /root/yz_aim_can0/parallel_cycle_test.py --can0-node 2 --usb-node 1 --minutes 1 --rpm 300 --move-ms 3000 --stop-ms 1000
```

`--minutes`默认30，最多60；`--rpm`为1~300电机RPM；`--move-ms`为1~5000ms；`--stop-ms`为0~60000ms，仅应用在正转之后。`--if can0`、`--lys 0`、`--channel 0`和`--library /root/yz_aim/lib/liblyscan.so`为默认通信参数。节点参数可为1~126，只选择已配置电机的地址，不执行set-node。

启动前应正常退出旧控制会话，并确认两路行程允许反复运动。脚本检查两路只读SDO和静止反馈，全部就绪后共同放行。任一路检查/运动失败即停止本次测试并通知另一路清理，不自动重发已开始或未确认的运动。保留原控制程序的报警和通信保护。达到时长后完成当前整组，因此实际总时间含启停和清理，可能稍超过设定时间。

前台运行时用Ctrl+C同时停止两路，并等待停止失能与报告生成。关闭SSH连接也会中断测试；若希望断开SSH后继续，可在板上已有的tmux/screen会话中运行本命令。不要同时启动两个入口。

两路日志使用完全相同的开始时间戳：

```text
/root/yz_aim_can0/logs/parallel-30min-YYYYMMDD-HHMMSS/
/root/yz_aim/logs/parallel-30min-YYYYMMDD-HHMMSS/
```

每次目录中实时保存`can-frames.log`、`controller.log`、`test.log`、`launcher.log`、`progress.json`和`coordinator.json`。逐帧信息只写入文件，不在启动终端刷屏；通信中文摘要约每分钟写入test.log，异常即时写入。结束后保存`summary.json`、`analysis.json`及两轴合并中文总结：

```text
YZ-AIM_两轴通信统计_YYYYMMDD-HHMMSS_30分钟.md
```

相同报告在两个本次目录和两个项目的logs根目录各保存一份；1分钟等测试按实际设置命名。报告有CAN收发、错误帧、CAN0内核错误/丢弃增量、逐对象SDO请求与应答/重发/延迟、心跳以及转速和位置反馈。USB SDK未提供适配器硬件丢帧计数，报告会标为不可用，不把SDO未确认直接认定为物理CAN丢帧。

实时查看本路动作与通信统计（把时间戳换成本次启动时打印的目录）：

```bash
tail -f /root/yz_aim_can0/logs/parallel-30min-YYYYMMDD-HHMMSS/test.log
tail -f /root/yz_aim/logs/parallel-30min-YYYYMMDD-HHMMSS/test.log
```

如需重新生成报告，原始结果仍在时可运行：

```bash
python3 -B /root/yz_aim_can0/parallel_cycle_report.py /root/yz_aim_can0/logs/parallel-30min-YYYYMMDD-HHMMSS/coordinator.json
```

本次交付仅完成文件/伪终端模拟验证、参数预览及安装校验，没有开启实际电机测试。运行后根据真实反馈和日志判断硬件测试结果。
