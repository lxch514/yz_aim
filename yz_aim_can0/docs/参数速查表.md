# YZ-AIM 电机参数速查表（配合 yz_aim / yz_aim_can0 使用）

依据：`YZ-AIM-CanOpen用户手册_v1.65_出线版`（原始 md 在 `yz_aim/docs/`）与本套程序源码实测。

---

## 一、通信方式：只用 SDO + 心跳

两套程序在 CANopen 层完全一致，**不使用 PDO、不使用 NMT、不使用 SYNC**。

程序发出的帧只有两种：

| CAN ID | 方向 | 内容 |
|---|---|---|
| `0x600 + node` | 程序 → 电机 | SDO 请求。读 `CS=0x40`；写 1 字节 `0x2F` / 2 字节 `0x2B` / 4 字节 `0x23` |
| `0x580 + node` | 电机 → 程序 | SDO 应答。读回 `0x4F`/`0x4B`/`0x43`；写成功 `0x60`；出错 `0x80` + 4 字节 abort 码 |
| `0x77F` | 程序 → 电机 | 心跳，1 字节 `0x05`（Operational），约每 200 ms 一条 |

要点：

- 只用**加速传输**（expedited），数据宽度仅 1 / 2 / 4 字节；不用分段传输，不用块传输。
- 心跳是把程序当成 **node 127 的生产者**，把驱动的消费者 `0x1016:1` 临时改成 `(0x7F<<16)|1000`（1000 ms），退出时还原原值。默认值是 `0x7F07D0`（node 127 / **2000 ms**）。
- SocketCAN 的接收过滤表里虽然留了 TPDO（`0x180+N`、`0x280+N`、`0x380+N`、`0x480+N`），但代码只把 `0x580+N` 当应答，其它帧**收到即丢**——这是为了排空队列，避免陈旧的 SDO 应答被埋在周期报文后面。
- 两套差异只在传输层：`yz_aim` 用 `dlopen liblyscan.so` 走 USB-CAN 适配器；`yz_aim_can0` 用 SocketCAN。LYS 适配器虽支持 CAN FD，但配置里 `fd_enable = 0`，实跑的是经典 CAN 2.0B，所以两套帧格式完全一样。

> 想上 PDO 的话：RPDO1 `0x200+N` = 控制字+模式+目标位置；RPDO3 `0x400+N` = 控制字+模式+目标速度；TPDO1 `0x180+N`。RPDO4 `0x500+N` 需配 SYNC(`0x080`) 才执行。

## 二、换算基准与量程（必须记牢）

| 项目 | 值 |
|---|---|
| 电机脉冲 | 32768 / 电机圈 |
| 减速比 | 51 : 1 |
| 输出轴 | 1 671 168 脉冲 / 输出圈 |
| 多圈记忆范围 | ±60000 圈（±1 966 080 000 脉冲 ≈ ±423 529° 输出） |
| 电机转速上限 | 3000 RPM（`0x60FF` 手册范围 -3000~3000） |
| 0x606C 实际速度 | 返回值 ÷ 10 = 电机 RPM |
| 0x260E 报警码 / 0x6078 电流 | 电流 = 值 ÷ 2000（A） |
| 0x6079 电压 | 电压 = 值 ÷ 327（V） |
| 0x2612 温度 | 直接摄氏度 |
| 0x261E 多圈电池电量 | 0~10 → 0%~100%；<60% 自动充电 |

### 只读（诊断）

| 索引 | 名称 | 宽度 | 说明 |
|---|---|---|---|

| `0x6041:0` | 状态字 | 2 | 见下方位定义 |
| `0x260E:0` | 报警码 | 2 | 见报警码表 |
| `0x2601:0` | 输出使能 | 2 | bit0 = 1 表示输出已使能 |

| `0x606C:0` | 实际速度 | 2 | ÷10 = 电机 RPM |
| `0x6078:0` | 实际电流 | 2 | ÷2000 A |
| `0x6079:0` | 系统电压 | 2 | ÷327 V |
| `0x2612:0` | 系统温度 | 2 | ℃ |
| `0x261E:0` | 多圈电池电量 | 2 | 0~10 |

### 读写（控制）

| 索引 | 名称 | 宽度 | 程序里怎么用 |
|---|---|---|---|
| `0x6040:0` | 控制字 | 2 | 使能 `0x000F`、急停 `0x010F`、清操作位 `0x0100`、相对位 `0x004F`→启动 `0x005F`、绝对 `0x002F` |
| `0x6060:0` | 工作模式 | 1 | 1=位置，3=速度，6=找原点，7=插补 |
| `0x607A:0` | 目标位置缓存 | 4 | 绝对/相对位置模式的目标 |
| `0x6081:0` | 梯形速度 | 4 | 位置模式速度 0~3000 RPM；程序默认会话值 30 |
| `0x6083:0` | 电机加速度 | 4 | 程序固定写 500 (r/min)/s。**注意它一身三职**：>60000 时禁用内部加减速曲线；写 1/0 开关限位功能；改波特率时借它写 800~803 |
| `0x60FF:0` | 速度模式速度 | 4 | 速度模式目标转速 |
| `0x2601:0` | 驱动器输出使能 | 2 | 程序使能/失能时写 1 / 0 |
| `0x261D:0` | 最大允许电流 | 2 | 单位 mA，0~10009。个位 1~9 = 达到最大电流持续 1~9 秒报警停机；个位 0 = 不报警 |
| `0x1016:1` | 心跳消费者 | 4 | `(生产者地址<<16) \| 超时ms`；0 = 不监测 |
| `0x1017:0` | 心跳产生间隔 | 2 | 单位 ms，0 = 不产生；默认 1000 |

### 厂商特殊（慎动）

| 索引 | 名称 | 宽度 | 关键取值 |
|---|---|---|---|
| `0x2600:0` | Modbus 使能 / 命令通道 | 2 | `1` 进入内部参数模式；`506` 提交；`2` 才能保存 TPDO 值 |
| `0x2604:0` | 弱磁角度（被借用为"命令确认"） | 2 | 限位功能写 `131`；改波特率写 `129` |
| `0x260A:0` | 电子齿轮分子 | 2 | 默认 32768；写 `60006` 再写 `60016` = **置多圈零点**；写 0 → 上电默认 Modbus 使能 |

| `0x2614:0` | 参数保存标志 | 2 | 写 `1`（保存中），读 `2` = 保存完毕 |
| `0x2615:0` | 设备地址（节点号） | 2 | 0~255，**保存后断电重上电才生效** |
| `0x2618:0` | 静止最大允许输出 | 2 | 0~609 → 0~60.9%；个位 1~9 = 堵转报警时间，个位 0 = 不报警 |
| `0x2619:0` | 特殊功能 | 2 | 0=脉冲+方向；2=编码器跟随；3=占空比调速；6=上电自动回多圈零点；7=CANopen 插补；30~32768 = 上电自动转到 X×360/32768 度 |

| `0x60FB:1` / `0x60FB:2` | 位置环 KP / 速度前馈 | 2 | KP 60~30000 |
| `0x6098:0` | 回原点方法 | 1 | 17~21（17 负限位接 DIR，18 正限位接 PU，19/21 原点开关接 DIR） |

## 四、位定义

### 控制字 0x6040

| bit | 定义 |
|---|---|
| 0 | 启动 |
| 1 | 电压输出 |
| 2 | 允许急停 |
| 3 | 允许操作 |
| 4 | 执行新设定点（写 1 生效后自动回 0） |
| 5 | 位置立即生效 |
| 6 | 0=绝对位置 / 1=相对位置 |
| 7 | 故障复位 |
| 8 | 停止（急停但保持自锁） |

### 状态字 0x6041

| bit | 定义 |
|---|---|
| 15 / 14 | 正限位 / 负限位到达 |
| 13 / 12 | 找原点错误 / 找原点完成 |
| 10 | 目标达到：位置模式=到位；速度模式=达到给定速度 |
| 8 | 无 |
| 5 / 4 | 允许急停 / 电压输出 |
| 3 / 2 | 伺服报警 / 允许操作 |
| 1 / 0 | 启动 / 准备启动 |

## 五、报警码与指示灯

| 报警码 | 红灯 | 原因 | 处理 |
|---|---|---|---|
| `0x20` | 二长闪 | 通讯掉线 | 重发心跳即可恢复；电机已停机 |
| `0x10` | 一长闪 | 电池掉电（刹车版=轴动超 ±5°，仅提示） | 重设多圈零点 |
| `0x12` | 一长闪 2 短闪 | 堵转 | 停机；EN 发 1 或控制字清报警位可恢复 |
| `0x14` | 一长闪 4 短闪 | 失速 | 停机；同上 |
| `0x15` | 一长闪 5 短闪 | 过压（>52V） | 加放电模块 |

绿灯：常亮=正常且电池满；闪烁=正常且充电中；高频闪=电池掉线。

## 六、四条"改完必须断电重上电"的隐藏操作

### 1. 置多圈零点（`set-zero` 命令）

`0x260A`（电子齿轮分子）写 `60006` → 再写 `60016`。完事后分子自动回原值，`0x6064` 应变成 0 或个位数。没变成 0 就重做。程序里 `set-zero` 需要 `--yes`。

### 2. 改节点号（`set-node` 命令）

`0x2615` 写新地址 → `0x2614` 写 1 → 轮询 `0x2614` 读到 2 = 保存完成 → **断电重上电生效**。

### 3. 改波特率（`set-bitrate` 命令）

严格按顺序，**不要发参数保存标志**（这是内部参数）：

1. `0x2600` 写 `1`
2. `0x6083` 写波特率代码：`803`=1M，`802`=500K，`801`=250K，`800`=125K
3. `0x2604` 写 `129`
4. `0x2600` 写 `506`

**断电重上电生效。**

### 4. 开启位置限位功能

1. `0x6083` 写 `1`（1=开启，0=关闭）
2. `0x2604` 写 `131`
3. `0x2600` 写 `506`

**断电重上电生效。** 之后用 `0x261F` / `0x2620` 设上下限，再 `0x2614` 写 1 保存。
启用后：位置模式只能在限位区间内；速度模式超过限位会把速度自动置 0。

> 官方文档里"参数保存标志"有几处误写成 `26000010`，正确地址是 `0x2614`；7.08.4 用值 `5` 也与其他章节不一致。本程序按 `0x2614` 写 1 / 轮询 2 实现，与寄存器列表一致。

## 七、接线与物理层

- 电源：`+V` / `GND`，**+24V~36V**，正负接反会短路甚至烧驱动器。大惯性负载建议电源端并 50V 1000μF。
- DB9 公头：`1 PU+`(蓝) `2 PU-`(蓝黑) `3 DIR+`(绿) `4 DIR-`(绿黑) `5 WR+`(红白) `6 ZO`(黄) `7 COM`(黑白) `8 CANL`(棕) `9 CANH`(白)。
- **CANH = 白线，CANL = 棕线**，别按网线习惯接。电机内**没有** 120Ω 终端电阻，需在距控制器最远处并 1 个 120Ω。
- 量 CAN_H–CAN_L 阻值：一端 120Ω ≈ 120Ω；两端都有 ≈ 60Ω；∞ = 没有终端电阻。
- RK3588 的 CAN 是 TTL，必须经底板收发器才能上总线。
- 上电后正常时绿灯亮、红灯灭；一秒一条 `0x701` 心跳（数据 `05`）。

## 八、现场易踩的坑

1. **不要用 `rx_packets` 判断总线是否有数据**。控制器停在 `ERROR-PASSIVE` 时该计数会虚增约 125 帧/秒，但 `AF_CAN` 一帧都收不到。先 `can0_up.sh` 复位到 `ERROR-ACTIVE`。
2. **`0x6083` 是"加速度/限位开关/波特率代码"三合一**，别随手改它。
3. **一次 SDO 超时会把整个会话毒化**（`ambiguous SDO session`），之后连 `stop`/`disable` 都被拒绝，只能 `quit` 重开。所以务必一条一条看结果，失败就重开，不要连着敲。
4. 速度模式（`jog` / `spin`）期间程序每 ~70 ms 读 `0x6041`/`0x260E`/`0x606C`/`0x6064`；报警、限位、超速、位置越界都会立刻停机。
5. `<60000` 的加速度才会启用驱动器内部加减速曲线；`≥60000` 表示由外部脉冲自己带加减速。
6. 找原点速度由**加速度的个位**决定：个位 0~9 对应 100~1000 RPM（如 `10005` → 600 RPM）。
