# 双轴命令速查 1.1.0-minimal

完整语义见 [双轴同步使用说明](双轴同步使用说明.md)。默认方向：extend=节点2正、节点1反；retract相反。

```sh
cd /root/yz_aim_can0_double
./build/yz_aim_can0 --if can0 --node 1 --node2 2
```

```text
sync-enable
sync-zero
extend 300 50000
retract 300 50000
sync-status
sync-disable
quit
```

| 命令 | 含义 |
| --- | --- |
| `sync-zero` | 两轴静止时记录本会话固定软件零点，运动中不能更改 |
| `extend <rpm> <ms>` / `retract <rpm> <ms>` | 1~300电机RPM，1~600000ms；领先轴可有限减速 |
| `sync-correct <0~10RPM>` | 最大减速修正，默认5，另受名义速度10%限制 |
| `sync-tol <输出度>` | 有效反馈累计偏差保护，默认0.5度，不会逐拍重置基准 |
| `sync-drift <RPM>` | 速度差告警参考，不放宽累计位置保护 |
| `sync-run <带符号rpm>` / `sync-stop` | 常转 / 同时停止并结束日志 |
| `sync-status` | 状态、固定零点相对行程及修正设置 |
| `sync-dir 2 1` | 默认极性；只在停止时修改 |
| `sync-disable` | 先同时停止再逐轴确认失能 |

日志：本目录 `logs/*.csv`，结尾包含设定时间、触发时间、停止请求和停稳确认时间。

改号时只接目标电机：

```sh
./build/yz_aim_can0 --if can0 --node 1 --node2 0 --yes set-node 2
```

保存确认后仍需重新上电，以新节点读取确认。真实故障、限位、失联、反馈持续过期和危险累计错位仍会停止。离线测试不等于实机长跑验证。
