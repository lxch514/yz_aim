# 双轴操作说明 1.1.0-minimal

默认伸出方向保持：节点2正、节点1反；缩进相反。命令只用英文 `extend` / `retract`。

## 启动与日常操作

```sh
cd /root/yz_aim_can0_double
./build/yz_aim_can0 --if can0 --node 1 --node2 2
```

can0 按原有方式准备好后，进入程序执行：

```text
sync-enable
sync-zero
extend 300 50000
retract 300 50000
sync-status
sync-disable
quit
```

`sync-zero` 前先把机构放在正确初始位置，并确认两轴静止。它只记录本会话的软件基准，不移动电机、不写硬件原点。后续动作不会重新置零；重启程序后须重新确认零点。没有记录零点会拒绝双轴速度运动，运动中也拒绝重新置零。

速度单位是电机 RPM，1~300；时间单位是毫秒，1~600000。`300` 是名义速度及上限，领先轴允许小幅减速修正。默认最大修正5 RPM，另受名义速度10%限制；不反向、不超速。例：`sync-correct 3` 将最大减速修正设为3 RPM；只在停止时设置。增益为10 RPM/输出度，死区0.02输出度，修正变化率20 RPM/s，仍需按实机机构验证。

所有速度入口 `extend` / `retract` / `sync-spin` / `sync-run` / 双轴 `jog` 共用此逻辑。`sync-run 300` 常转到 `sync-stop`；位置命令 `sync-rel` / `sync-abs` / `sync-mm` 沿用原有位置模式。

## 日志与时间

每条双轴速度动作自动在本目录 `logs/` 生成CSV。记录原始位置、对齐位置、相对固定零点的两轴行程、偏差、目标/实际转速、采样年龄/质量、报警与结束原因；约100ms目标周期，按实际采样时刻记录。磁盘写入由日志线程处理，不占用 CAN 工作线程。屏幕不逐拍刷数据，运动结束给出日志路径和汇总；运行中可用另一终端 `tail -f` 查看CSV。

CSV元数据包含两个原始零点、节点、名义速度、设定时长和构建时间。结尾分别记录触发时刻、两轴停止请求时刻和停稳确认时刻。设定时间从首条目标写入前的共同起点计时，到时先向两轴发停止，再确认；物理减速时间另外记录，普通Linux/SDO不承诺0ms误差。

默认方向下：`x1=-(p1-p10)`、`x2=p2-p20`、`error=x2-x1`。所有坐标差使用64位整数。速度/位置的主机事务中点用于时间对齐，CSV保留估计加速度和两类采样年龄；重试、过期或跨度过大的样本只记质量告警，不用于调速，持续1000ms无可用配对反馈会停止。

## 保护与校正

`sync-tol` 默认仍为0.5输出度，未擅自扩大机械允许错位。有效反馈的真实累计偏差连续3拍超限仍停；不再按每拍重取基准来隐藏累计错位。启动期间用两次速度采样估计加速度（限制在已设定的±500 RPM/s内），同时对齐速度和位置采样，累计偏差保护不关闭；有限调速在名义加速时间加200ms后启用。启动期间仍检查驱动报警、限位、反馈质量、实测超速及实际转向。

`sync-drift` 现在只是速度差告警参考，不再让位置门限随时间扩大；`sync-correct` 控制有限减速修正。真实报警、限位、失联、持续反馈过期及危险累计错位保留停机。不得将 `sync-tol 0` 当成解决不同步的办法。机构允许的最大错位仍需现场确认；若现有0.5度保护被真实错位触发，应检查负载、初始对齐和校正参数，不能盲目放宽。

两轴速度目标成对连发、再分别确认；启动控制字也成对连发，不等待A轴应答后才给B轴启动，减少SDO往返造成的起步时差。

共享总线只维护一份 `0x77F` 心跳计时，SDO等候期间也服务心跳。真正超期后不自动恢复旧运动。到时结束显示“正常停止”；故障停止给出具体原因，不再把结束时间到当成读失败锁止会话。

## 命令改节点号

只接需要改号的一台（两台同为ID1时无法分别寻址）：

```sh
cd /root/yz_aim_can0_double
./build/yz_aim_can0 --if can0 --node 1 --node2 0 --yes set-node 2
```

程序自动停止、确认失能，先安装旧/新SDO应答过滤，再写入0x2615并校验、写0x2614=1保存，轮询读到2才报告完成。写操作不盲目重发。改号后会话结束，给驱动器重新上电后用新节点读回确认，再接回另一台ID1。

新ID范围1~126；127由本程序用作心跳生产者。未加 `--yes` 或未用 `--node2 0` 会拒绝改号；命令失败返回非零退出码。该命令不修改板载can0的波特率。
